YomitoriRss repository architecture

Composition root → feature ownership → shared technical capabilities

Primary ownership path

  • :app owns app-shell composition and platform wiring
  • Feature UI owns state and presentation
  • Domain defines contracts; Data implements them

Shared capabilities

  • core modules expose narrowly named technical capabilities
  • core never depends on feature
  • Application-scope runtimes are composed once and reused

Enforced boundaries

  • domain → UI/Data is forbidden
  • UI → concrete Data is forbidden
  • Durable persistence stays with its owning feature
