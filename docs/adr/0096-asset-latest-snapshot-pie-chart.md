# ADR-0096: 最新資産スナップショットのカテゴリ構成を円グラフでも表示する

- Status: Accepted
- Date: 2026-08-18
- Updated: 2026-09-06
- Amends: ADR-0095

## Context

ADR-0095 では最新スナップショットのカテゴリ別金額と構成比を一覧で表示し、履歴は積み上げエリアグラフで可視化する方針とした。一覧は正確な金額と比率の確認には向くが、最新時点でどのカテゴリが資産全体の大きな割合を占めるかは視覚的に把握しにくい。

当初の ADR-0095 は負の資産明細も read model へ含めていたため、円グラフでは負数を除外する追加ルールが必要だった。2026-09-06 の ADR-0095 更新で、負の金額はインポート時に保存対象から除外し、既存負数も read model で無視する方針へ変更した。したがって通常の UI flow では円グラフへ負数が到達しない。

## Decision

最新スナップショットのカテゴリ別内訳は、既存の一覧に加えて円グラフでも表示する。

円グラフの入力は最新履歴ポイントの `byCategory` とし、一覧および履歴グラフと同じカテゴリ集計を使用する。カテゴリ色も ADR-0095 で定めた安定したカテゴリ色マップを共有し、円グラフと一覧の対応を追いやすくする。

円グラフには金額が正のカテゴリだけを含め、その合計を360度として各カテゴリの角度を算出する。0 は面積を持たないため除外する。負数は通常の read model には存在しないが、描画用の純粋関数では防御的に0以下を除外し、負数を絶対値へ変換して構成比へ混在させない。正のカテゴリが存在しない場合は円グラフを表示しない。

角度計算はUI描画から分離した純粋関数とし、合計が360度になること、0以下のカテゴリを除外すること、正のカテゴリがない場合の挙動を単体テストで保証する。

## Consequences

- 最新時点のカテゴリ構成を一覧の数値と円グラフの面積の両方で確認できる。
- 履歴グラフ、円グラフ、一覧でカテゴリ色が一致する。
- 通常の資産 read model は負数を含まないため、負数専用のユーザー向け注記を表示する必要はない。
- 描画用関数自体は0以下を除外するため、将来不正な入力が渡っても負額を絶対値変換して構成比の意味を変えることはない。

## Public repository safety

円グラフのテストには人工的なカテゴリ名と金額だけを使用し、実際の資産名、口座名、金額などの個人情報をリポジトリへ追加しない。

## Relationship to existing ADRs

- ADR-0095 の資産履歴管理・カテゴリ集計・カテゴリ色の方針を維持し、最新スナップショットの表示方法だけを拡張する。
- 2026-09-06 の ADR-0095 更新により、負数除外の primary boundary は Data read/import 側へ移った。円グラフの0以下除外は防御的な描画契約として残す。
- ADR-0055 の番号管理方針に従い、0096 を使用した。
