# ADR-0034: 蔵書一覧では由来サービスを明示し、表示上の条件で絞り込む

- Status: Accepted
- Date: 2026-08-13
- Amended: 2026-08-18
- Refines: ADR-0013

## Context

ADR-0013 では `LibraryBook.source` と `LibrarySource` により Google Play Books、Kindle、Audible をサービス非依存の蔵書モデル上で区別している。

複数サービスの蔵書を同じ「全体」「シリーズ」画面へ表示すると、同一・類似タイトルが混在した際にどのサービス由来かを一覧から判断しづらい。また、特定サービスだけを確認するための絞り込み手段がなかった。

蔵書数が増えると、サービスやシリーズのグリッドだけでは特定の書籍を探すのに時間がかかる。タイトルだけでなく、著者・出版社・シリーズ名など、すでに `LibraryBook` に保持しているメタデータから直接絞り込める必要がある。

## Decision

- 書籍カードには常に `LibrarySource.label` を表示し、フィルタ未使用時でも由来を判別できるようにする。
- 「全体」「シリーズ」「非表示」は共通の由来フィルタ状態を使う。
- フィルタ候補は「すべて」と `LibrarySource.entries` から生成し、Google Play Books / Kindle / Audible / ファイルサーバの追加・名称変更とUI定義を二重管理しない。
- 「全体」「シリーズ」「非表示」は共通のテキスト検索語も使い、タブ移動後も検索条件を維持する。「設定」には検索欄を表示しない。
- テキスト検索は入力中に表示結果へ反映する部分一致検索とする。検索対象はタイトル、著者、出版社、出版日、シリーズ名、ナレーター、ISBN、サービス側IDとする。
- 空白で区切られた複数の検索語は AND 条件とし、各検索語は検索対象フィールドのいずれかに大文字小文字を区別せず一致すればよい。
- 由来フィルタとテキスト検索は組み合わせて適用し、シリーズ表示は絞り込み後の書籍集合から構築する。
- フィルタと検索は表示上の絞り込みだけとし、Repository、DB、同期・インポート済みデータは変更しない。

## Consequences

### Positive

- 混在一覧でも各書籍の由来を直接確認できる。
- 特定サービスだけを「全体」「シリーズ」「非表示」で確認できる。
- タイトルが曖昧でも、著者やシリーズ名など既存メタデータから目的の蔵書へ到達できる。
- サービス別絞り込みと検索語を組み合わせられるため、蔵書数が増えても候補を段階的に減らせる。
- 既存の `LibrarySource` と `LibraryBook` の値だけを利用するためDBマイグレーションや再インポートは不要になる。
- フィルタ後にシリーズを構築するため、件数と展開内容が現在の条件に一致した蔵書だけを反映する。

### Negative

- 書籍一覧の上部に検索欄が増えるため、グリッドに使える縦方向の領域が少し減る。
- 検索は現在メモリ上にある蔵書をUI層で走査するため、将来蔵書数が大幅に増えた場合はDB側の検索やインデックスを再検討する必要がある。
- フィルタと検索語は画面状態であり、アプリ再起動後まで永続化しない。

## Relationship to existing ADRs

- ADR-0013 の `LibraryBook.source` / `LibrarySource` を表示・絞り込みの正規軸として利用する。
- ADR-0018 の「全体」「シリーズ」「非表示」「設定」のタブ構成を維持し、閲覧系3タブだけに共通の検索条件を適用する。
- サービス固有の取得方式は引き続き data layer に閉じ込め、UIフィルタやテキスト検索から同期・インポート処理へ依存を追加しない。
