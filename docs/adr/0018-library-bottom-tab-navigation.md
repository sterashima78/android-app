# ADR-0018: 蔵書を全体・シリーズ・設定の下部タブに分離する

- Status: Accepted
- Date: 2026-08-10

## Context

蔵書画面では、Google Play Books の同期、表示中/非表示の切り替え、シリーズ単位の折りたたみ表示、書籍ごとのシリーズ編集が1つの縦長画面に混在していた。

一方、RSS・Reddit・ブックマークでは、同一機能内の主要な表示モードを画面下部のタブで切り替える。蔵書も同じ操作モデルに揃え、閲覧と管理設定を分離したい。

ADR-0017 ではシリーズ単位にまとめる表示を蔵書一覧そのものとして定義していたが、シリーズを意識せず全冊を確認したい場合にはフラットな一覧も必要になる。

## Decision

蔵書 feature の画面を次の3タブに分け、Material 3 の下部 NavigationBar で切り替える。

- 全体: 非表示ではない蔵書をシリーズでまとめず、書籍単位のグリッドとして表示する
- シリーズ: ADR-0017 のシリーズ推定・手動設定を利用し、シリーズ見出しを折りたたみ表示する。シリーズ未設定の書籍もこの画面から確認できる
- 設定: Google Play Books の同期状態と同期操作、表示中/非表示の件数、非表示にした蔵書の再表示操作を提供する

書籍の「非表示」と「シリーズ編集」は閲覧中の文脈で実行する操作なので、全体・シリーズの各書籍から引き続き利用できる。非表示書籍のシリーズ編集も設定画面から維持する。

蔵書タブは library feature 内の表示状態として扱い、domain/data のモデルや永続化形式は変更しない。アプリ全体のドロワー上では引き続き「蔵書」を1つの section として扱う。

蔵書画面はアプリ全体の Scaffold 内に配置されるため、library feature 側の NavigationBar では system bar inset を重複適用しない。

## Consequences

### Positive

- RSS 等と同様に、蔵書内の主要な表示を下部タブで直接切り替えられる
- 全冊をフラットに見る用途と、シリーズ単位で見る用途を分離できる
- 同期・非表示管理が閲覧画面から外れ、蔵書閲覧時の情報密度が下がる
- domain/data の変更が不要で、既存のシリーズ情報・非表示状態・同期キャッシュをそのまま利用できる

### Negative

- 蔵書 feature 内に独立したタブ状態を持つため、アプリ全体の MainTab とは別に画面状態を管理する必要がある
- 非表示書籍の一覧は設定タブへ移動するため、従来より1回タブ操作が増える

## Relationship to existing ADRs

- ADR-0013 のサービス非依存な蔵書モデルと Google Play Books 同期方式は変更しない
- ADR-0014 の非表示状態の永続化方式は変更せず、非表示一覧の表示場所だけを設定タブへ移す
- ADR-0017 のシリーズ推定・手動設定・折りたたみ表示を維持し、その表示場所をシリーズタブとして明確化する
- ADR-0017 に記載された「シリーズ表示を蔵書一覧そのものとする」UI 配置については、本 ADR の全体/シリーズ分離を優先する
