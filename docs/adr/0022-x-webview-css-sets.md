# ADR-0022: X WebView のカスタム CSS は3つのローカルセットとして保持する

- Status: Accepted
- Date: 2026-08-11
- Amended by: ADR-0060

## Context

ADR-0115 では X WebView にローカル CSS を注入し、CSS の有効/無効、編集、要素選択からの非表示ルール追加を `:feature:x:ui` 内で扱う方針を決定した。また将来変更として複数 stylesheet の切り替えを挙げていた。

その後、X 本来の表示を初期状態とするため `x_viewer.css` のデフォルト内容は空になった。一方、用途ごとに CSS を切り替えて試せるよう、複数の CSS を端末内に保持し、現在の CSS を別のセットへ複製したい要件が生じた。

CSS は X の表示だけに関係する presentation preference であり、同期や共有を必要としないため、domain/data module を追加する理由はない。

## Decision

- X のカスタム CSS は最大3セットを固定スロットとして `SharedPreferences` に保持する。
- 3セットのうち1つを「現在のセット」として選択し、X WebView へは現在のセットだけを注入する。
- CSS の有効/無効はセットごとではなく従来どおり X カスタム CSS 全体の設定として保持する。
- 設定画面ではセット1〜3を切り替えて編集できるようにする。
- 現在のセットの CSS を、現在以外の任意のセットへコピーできるようにする。コピー先に内容がある場合は上書きする。
- コピー操作は設定ダイアログ内の編集状態として扱い、「保存」を押した時点で永続化する。「キャンセル」した場合は永続化しない。
- 要素選択機能で生成した非表示ルールは、現在選択されているセットへ追加する。
- 「デフォルト CSS に戻す」は現在のセットだけを `x_viewer.css` の内容へ戻す。現時点のデフォルト CSS は空である。
- 現在のセット番号が不正な値になっていた場合は 1〜3 の範囲へ補正して読み込む。
- 保存済み CSS は引き続き端末ローカルの `SharedPreferences` にのみ保持し、バックアップや外部同期の対象には今回含めない。

当初は従来の単一 CSS 設定キー `custom_css` をセット1へ読み替える互換処理を持たせていた。この互換処理は ADR-0060 により現行版の更新ベースラインから外し、3セット形式のみを読み書きする。

この決定は ADR-0115 の「単一の保存済み CSS を使用する」という部分と、「複数 stylesheet の切り替えを将来変更とする」という部分を更新する。また ADR-0115 に記載されたデフォルト CSS の sidebar/Grok 非表示ルールは現在の実装には適用せず、デフォルト CSS は空とする。

## Consequences

### Positive

- X の表示調整を3パターンまで端末内に保存し、用途に応じて切り替えられる。
- 既存セットを複製して一部だけ変更する試行が容易になる。
- X 専用の presentation preference という責務は変わらず、追加 module や database migration を必要としない。
- 現在利用しない単一 CSS 形式を実装から除去できる。

### Negative

- コピー先の内容は上書きされるため、保存前にコピー先の内容を確認する操作は提供しない。
- セット名は固定の「セット1〜3」であり、ユーザーによる名称変更は今回扱わない。
- CSS は端末ローカルのため、端末変更時やアプリデータ削除時にはセットも失われる。
- ADR-0060 以降は `custom_css` だけを持つ古い状態からの自動移行を保証しない。

## Relationship to other ADRs

- ADR-0115 の X WebView / CSS 注入 / 要素選択方針を維持し、CSS の保存モデルとデフォルト CSS に関する部分だけを本 ADR で更新する。
- ADR-0003 の feature-first 構成に従い、`:feature:x:ui` 内で完結させる。
- ADR-0060 により、単一 CSS 設定キーから3セット形式への互換読み取りを廃止する。
