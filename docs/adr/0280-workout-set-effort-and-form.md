# ADR-0280: Workout のセット別負荷とフォームを任意で記録する

- Status: Accepted
- Date: 2026-10-09
- Refines: [ADR-0276](0276-workout-ai-review-history.md), [ADR-0131](0131-workout-health-connect-export.md)

## Context

回数・時間・メモだけでは主観的強度、負荷条件、フォーム、実際の休憩を比較できない。レビューは記録されていない値を推定しないため、一次情報の入力能力を拡張する。

## Decision

- Workout Context が所有する `WorkoutSet` に任意の RPE（1〜10）、フォームの状態（安定・崩れ・痛み/違和感）、負荷条件の種類と値、セット前の実休憩秒数を追加する。
- 負荷条件は身体の傾斜、追加重量、補助重量、その他を区別する。重さは kg、身体の傾斜は姿勢を選択式で入力する。種目名から値を推定しない。
- 記録画面では詳細を未入力のまま保存できる。明示的な操作で同一種目の前回の負荷条件のみ再利用できる。RPE・フォーム・実休憩は再利用しない。
- タイマー設定値やセット間のタイムスタンプ差は実休憩として保存しない。未入力の休憩時間を AI が推定しない。
- 永続 payload のバージョンを4とし、3および既存の2は新しい項目を未入力として解釈する。未知バージョンは拒否する。後方互換の終了条件は既存方針を維持する。
- AIのメニュー提案とレビューでは、保存済みの実測・主観記録を一次情報として渡し、異なる負荷条件の回数を単純比較しない。外部運動履歴への export 契約は変更しない。
- 既存の feature-owned 保存領域とバックアップを利用し、別のデータ管理や cross-context import を増やさない。

## Consequences and verification

Workout Domain / UI / Data とAI入力、履歴テキスト、互換性テストを更新する。新しい module、permission、table、Worker、外部送信先は設けない。セットの任意値・復元・旧バージョン・AI入力境界を検査する。
