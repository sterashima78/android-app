# ADR-0088: オフラインパズルゲームを Game feature 内で拡張する

- Status: Accepted
- Date: 2026-08-17
- Refines: ADR-0080

## Context

ADR-0080 では、一人用ゲームの一覧と画面遷移を `:feature:game:ui`、ゲーム固有ルールを `:feature:game:domain` が所有し、永続化や外部 I/O が必要になるまで data module を作らない方針を決定した。

数独、クロンダイク、スパイダーソリティアに続き、短時間で遊べるオフラインゲームとして 2048、ノノグラム、マインスイーパーを追加する。3ゲームとも UI から独立した状態遷移とルールを持つ一方、ネットワークや既存 feature のデータを必要としない。

## Decision

- 2048、ノノグラム、マインスイーパーを既存の `GameRoute` とゲーム一覧へ追加する。
- 各ゲームの盤面状態、入力規則、勝敗・完成判定、問題または盤面生成は `:feature:game:domain` の純 Kotlin コードとして実装し、JVM unit test で検証する。
- 各ゲームの Compose UI と `ViewModel` は `:feature:game:ui` に配置する。ゲーム一覧へ戻っても同じ `ViewModel` が生存している間は進行状態を保持する。
- 2048 は 4×4 とし、1回の移動につき各タイルを高々1回だけ結合する。盤面が変化した移動の後だけ 2 または 4 の新規タイルを追加する。
- ノノグラム初版は 5×5 とする。端末内の完成パターンから行・列ヒントを計算し、塗りと × 印を明示的に切り替えて入力する。完成判定は塗られたマスが解と一致することとする。
- マインスイーパー初版は 9×9、地雷10個とする。最初に開いたマスとその周囲8マスを地雷配置候補から除外し、初手で安全領域が必ず開くようにする。0マスからの連鎖展開と旗入力を domain で扱う。
- 今回は途中状態の永続化、オンラインランキング、外部アセット取得を追加しない。そのため `:feature:game:data`、ネットワーク権限、新規ライブラリ依存は追加しない。

## Consequences

### Positive

- 3ゲームとも Compose から独立してルールをテストできる。
- 既存の Game feature の責務境界を変えずにゲーム一覧を拡張できる。
- オフラインで完結し、アプリの既存データや認証情報へアクセスしない。
- 2048 はスワイプとボタン、ノノグラムとマインスイーパーは明示的な入力モードを用意するため、スマートフォン上でも誤操作を抑えやすい。

### Negative

- ノノグラムは 5×5 の固定サイズかつ端末内パターン集合からの生成であり、大盤面や任意問題生成は対象外である。
- マインスイーパーは初版では難易度選択を持たない。
- 3ゲームともアプリ終了後の途中再開には対応しない。

## Relationship

本 ADR は ADR-0080 の Game feature 境界を維持したまま対象ゲームを拡張する。ADR-0085 の盤面優先・コンテキスト入力方針は数独固有の判断として維持し、今回のゲームでは各ルールに適した入力方式を採用する。
