# ADR-0097: 資産カテゴリを登録マスタとして管理し割当を選択式にする

- Status: Accepted
- Date: 2026-08-18
- Amends: ADR-0095

## Context

ADR-0095 では `asset_categories` に「資産名 -> 現在のカテゴリ」を保存し、未設定を「その他」として扱うことを決めた。この構造だけでは、まだ資産項目を割り当てていないカテゴリを事前に登録できず、設定画面でカテゴリ名を資産項目ごとに自由入力する必要がある。

カテゴリを継続的な分類軸として利用するには、カテゴリ自体を登録でき、既存の資産項目をカテゴリ単位で確認しながら登録済みカテゴリへ移動できる必要がある。また、空の登録カテゴリもユーザーデータなのでバックアップ後に保持されなければならない。

## Decision

### カテゴリマスタ

`feature:asset:data` に `asset_category_definitions` を追加し、登録済みカテゴリ名を保存する。`asset_categories` は引き続き「資産名 -> 現在のカテゴリ」の割当だけを保持する。履歴明細にはカテゴリを保存しないという ADR-0095 の方針は維持する。

「その他」はシステム既定カテゴリとして常に登録済みカテゴリに含める。既存DBを更新するときは、`asset_categories` に既に存在するカテゴリ名を `asset_category_definitions` へ `INSERT OR IGNORE` で移行する。これにより、従来の自由入力で作られた分類を失わない。

カテゴリ名は前後空白を除去して保存し、空文字は拒否する。同名カテゴリの重複登録は拒否する。資産項目のカテゴリ変更時も対象カテゴリをマスタへ `INSERT OR IGNORE` してから割当を更新し、旧データなどから渡された既存カテゴリとの整合を保つ。

このschema変更は database version 21 として追加し、ADR-0047 に従って migration は `feature:asset:data` が所有する。

### 設定UI

資産画面の `設定` タブにカテゴリ登録操作を追加する。

登録済みカテゴリごとに現在の資産項目をグループ表示する。割当が0件の登録カテゴリも表示し、カテゴリが登録済みであることを確認できるようにする。

資産項目をタップしたときはカテゴリ名の自由入力を行わず、登録済みカテゴリをラジオ選択肢として表示して変更する。これにより表記揺れによる意図しないカテゴリ増加を防ぐ。

カテゴリの削除・名称変更は今回の対象外とする。割当済みカテゴリの削除時の扱いや履歴表示への影響を別途決める必要があるためである。

### バックアップ

バックアップ形式を v7 に更新し、`asset_category_definitions` を `assetCategoryDefinitions` として保存・復元する。v1〜v6 は引き続き復元可能とする。

v6以前のバックアップを復元した場合は「その他」を登録し、復元された `asset_categories` のカテゴリ名からカテゴリマスタを再構築する。これにより既存バックアップとの互換性を保つ。

カテゴリ登録・カテゴリ変更が成功した場合は既存の `BackupChangeScheduler` 経由の変更通知対象とする。

## Public repository safety

カテゴリ機能のテスト、ADR、PR説明には人工的な資産名とカテゴリ名だけを使用する。実際の資産名、口座名、金額その他の個人資産情報は追加しない。カテゴリマスタや割当の実データをログ出力しない。

## Consequences

- 資産項目がまだ存在しないカテゴリを先に登録できる。
- 資産項目をカテゴリ単位で確認して、登録済みの選択肢へ移動できる。
- 自由入力によるカテゴリ名の表記揺れを抑制できる。
- 既存のカテゴリ割当を壊さずカテゴリマスタ方式へ移行できる。
- 空のカテゴリもバックアップ・復元できる。
- カテゴリ削除や名称変更は別の設計判断が必要になる。

## Relationship to existing ADRs

- ADR-0095 のカテゴリ設定を、割当テーブルに加えてカテゴリマスタを持つ形へ拡張する。履歴とカテゴリ割当を分離する決定は維持する。
- ADR-0047 に従いschema/migrationを `feature:asset:data` が所有し、app compositionのdatabase versionを21へ更新する。
- ADR-0055 に従い、作成時点の最大番号0096より大きい0097を使用する。
