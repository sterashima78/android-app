# ADR-0287: RSSの優先参考登録をあとで読むに集約する

- Status: Accepted
- Date: 2026-10-16
- Amends: [ADR-0286](0286-rss-joint-preference-learning.md)

## Context

RSSの推薦条件学習では、長押しメニューから「優先参考に追加」を実行する操作と、「あとで読む」に追加するとき自動的に優先参考として登録する操作が併存していた。両者は同じ優先参考を生成するため、利用者の操作経路が重複している。

## Decision

- RSS未読一覧と統合一覧の長押しメニューから「優先参考に追加」を削除し、個別登録専用のUI callbackも廃止する。
- 優先参考の登録はRSS記事を「あとで読む」に新規追加した時に行う。RSS未読ウィジェットと統合一覧も既存の登録処理を利用する。
- 「あとで読む」保存失敗時は優先参考を登録せず、参考登録失敗時は保存を取り消さない。解除・復元では新規参考を登録しない。
- 除外参考の深い左スワイプ、優先・除外条件の同時学習、学習済み参考の保持、学習のdebounce、実行先選択とバックグラウンド処理は変更しない。
- ADR-0286にある長押しメニューへの優先参考登録操作の追加判断のみを本ADRで変更する。

## Consequences

- 利用者が優先参考を追加するには「あとで読む」に追加する必要がある。
- 新しい永続状態、DB migration、バックグラウンド処理、外部通信、依存関係は追加しない。
- 「あとで読む」登録と優先参考学習が連動する既存テストを維持し、統合一覧の補助メニューから単独登録項目が消えたことを確認する。
